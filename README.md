# Luna

Rode JavaScript e TypeScript na hora, nativo no macOS (Apple Silicon, macOS 15 ou mais novo).

Este repositório guarda só o que é público da distribuição: os downloads (Releases), o cask do Homebrew, a página de instalação e o feed de atualizações.

## Instalar

Pelo Homebrew:

```sh
brew install --cask uaibritto/luna/luna
```

Ou baixe o DMG mais recente em [Releases](https://github.com/uaibritto/homebrew-luna/releases/latest) e arraste o Luna para Aplicativos.

Página de instalação: https://uaibritto.github.io/homebrew-luna/
